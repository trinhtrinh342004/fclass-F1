## User Workflow Preference

- After completing an implementation task, create or use a feature branch, commit scoped changes, sync the branch with latest `origin/main`, push, and create a PR.
- If PR auto-merge or direct merge to `main` is available and checks/permissions allow it, perform it; otherwise report the exact blocker.
- Do not repeat reminders about this workflow unless user action is required or the user explicitly asks for status.
